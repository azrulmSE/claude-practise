# 20260911 — Login page (`/login`)

## Goal
- Clean, accessible login page at `/login` using Tailwind v4 + shadcn/ui
- Server-side validation (zod) via Server Action + `useActionState`
- Stub auth (demo creds) — real auth lib (Auth.js / Better Auth) = later task

## Scope
- In: page UI, split layout, email + password, show/hide pw, remember me, forgot-pw link, validation errors, pending state, redirect on success
- Out: real sessions/cookies, DB, signup page, `/forgot-password` page (link will 404 until built), social login

## Stack notes (Next 16)
- Read first: `node_modules/next/dist/docs/01-app/02-guides/forms.md`, `authentication.md`
- Form = Client Component w/ `useActionState(action, initialState)` → `[state, formAction, pending]`
- Action signature: `(prevState, formData)`
- React 19 resets form after action → return submitted email in state, use as `defaultValue`
- `redirect()` throws — call it outside try/catch

## Steps

### 1. Install deps
- `bunx shadcn@latest init` → creates `components.json`, `src/lib/utils.ts` (`cn()`), rewrites theme tokens in `src/app/globals.css`
- `bunx shadcn@latest add button input label card checkbox`
- `bun add zod` (`lucide-react` comes w/ shadcn init)
- Check: `bun dev` still boots, `/` renders

### 2. Schema + types — `src/lib/definitions.ts`
- `LoginSchema = z.object({ email: z.email(...).trim(), password: z.string().min(1, 'Password is required'), remember: z.boolean() })`
- `LoginFormState = { errors?: { email?: string[]; password?: string[] }; message?: string; email?: string } | undefined`
- Login pw rule = just required (strength rules belong on signup, not login)

### 3. Stub auth — `src/lib/auth-stub.ts`
- `import 'server-only'`
- `verifyCredentials(email, password): Promise<boolean>` → compare vs demo user (`demo@orca.dev` / `Password123!`)
- Add ~300ms delay so pending UI is visible
- `// TODO: replace w/ real auth provider`

### 4. Server Action — `src/actions/auth.ts`
- `'use server'`
- `login(prevState: LoginFormState, formData: FormData)`
  - parse: `email`, `password`, `remember: formData.get('remember') === 'on'`
  - `safeParse` fail → return `{ errors: z.flattenError(err).fieldErrors, email }`
  - creds wrong → return `{ message: 'Invalid email or password.', email }` (generic msg, no user enumeration)
  - ok → `redirect('/')`
- Never return password in state

### 5. Auth layout (split) — `src/app/(auth)/layout.tsx`
- Route group `(auth)` → URL stays `/login`, layout reusable for future `/register`, `/forgot-password`
- `grid min-h-svh lg:grid-cols-2`
- Left brand panel: `hidden lg:flex flex-col justify-between bg-primary text-primary-foreground p-10`
  - top: logo + app name
  - bottom: short tagline / quote
  - optional subtle gradient/pattern via Tailwind only
- Right: `flex items-center justify-center p-6 md:p-10` → `{children}`

### 6. Page — `src/app/(auth)/login/page.tsx`
- Server Component, `export const metadata = { title: 'Log in' }`
- Wrapper `w-full max-w-sm`
- Header: logo (mobile only, `lg:hidden`), `h1` "Welcome back", muted subtext "Log in to your account"
- Render `<LoginForm />`
- Footer text: "Don't have an account? Sign up" (link to `/register`, placeholder)

### 7. Password field — `src/components/auth/password-input.tsx`
- `'use client'`, wraps shadcn `Input`, `useState` for visible
- Toggle button absolute right inside input (`relative` wrapper, `pr-10` on input)
- `type="button"` (must not submit), `aria-label` "Show password"/"Hide password", `aria-pressed`
- Icons: `Eye` / `EyeOff` from lucide

### 8. Form — `src/components/auth/login-form.tsx`
- `'use client'`, `useActionState(login, undefined)`
- Fields (`grid gap-4`), each = `Label` + input + error `<p id="email-error" className="text-sm text-destructive">`
  - Email: `type="email"`, `autoComplete="email"`, `defaultValue={state?.email}`, `aria-invalid`, `aria-describedby`
  - Password: `PasswordInput`, `autoComplete="current-password"`; label row has "Forgot password?" link → `/forgot-password` (right aligned)
  - Remember me: shadcn `Checkbox name="remember"` + `Label`
- Form-level error: `state.message` in `role="alert"` box (`rounded-md border border-destructive/50 bg-destructive/10 p-3 text-sm`)
- Submit: `Button className="w-full" disabled={pending}` → `Loader2 animate-spin` + "Logging in..." when pending
- Keep HTML `required` for fast client check; server zod = source of truth

### 9. Design checklist
- Only theme tokens (`bg-background`, `text-muted-foreground`, `bg-primary`) — no hex values
- Spacing rhythm: `gap-6` sections, `gap-4` fields, `gap-2` label↔input
- Mobile-first: single column < `lg`, brand panel hidden
- Dark mode: check both themes via tokens
- Visible focus rings (shadcn default), logical tab order: email → forgot link → password → toggle → remember → submit
- Compose classes w/ `cn()`

### 10. Verify
- `bun run lint`
- `bunx tsc --noEmit`
- `bun dev` → http://localhost:3000/login
  - empty submit → browser required msg
  - bad email (disable `required` in devtools) → zod error under field
  - wrong creds → generic alert, email kept, pw cleared
  - demo creds → button pending + spinner → redirect `/`
  - resize < 1024px → brand panel gone, form centered
  - toggle pw → type text/password, focus stays in field
  - keyboard-only pass + dark mode pass
